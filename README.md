# PCA Analysis on Breast Cancer Gene Expression Data

## Overview
This project performs Principal Component Analysis (PCA) on breast cancer gene expression data to reduce dimensionality and visualize patterns in the dataset.

## Objectives
- Perform preprocessing of gene expression data
- Apply PCA for dimensionality reduction
- Visualize principal components
- Identify clustering patterns among samples

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Files
- `pca_analysis.py` : Main PCA implementation script
- `README.md` : Project documentation
- Dataset files : Input gene expression datasets

## Methodology
1. Load gene expression dataset
2. Normalize/preprocess the data
3. Apply PCA using Scikit-learn
4. Compute principal components
5. Visualize reduced-dimensional data

## How to Run

```bash
python3 pca_analysis.py
```

## Results
The PCA transformation reduces the high-dimensional gene expression dataset into lower-dimensional principal components while preserving maximum variance.
